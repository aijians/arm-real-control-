# 导轨配准与相对距离验收

配置省略 `vision.relative_measurement` 或设为 `null` 时，现有视觉入口继续工作。地面和在轨使用同一实现，各用本场景取景和分辨率对应的转正标定及基准帧。方案 E 的轴心平面为世界 Y=181.5 mm，既有模型杆身半径为 4 mm。相机安装位置或取景改变时，需要先核实标定与画面配套。

## 现场配置

在原有 `vision` 配置中加入如下字段。坐标和路径为格式示例，按实际转正基准帧取值。

```json
{
  "relative_measurement": {
    "reference_image": "runtime/relative_vision/reference_upright.png",
    "registration_rois": [[350, 150, 410, 170], [558, 211, 600, 253], [674, 292, 690, 314]],
    "stem_radius_mm": 4.0,
    "stop_reference_frames": {
      "蓝": {
        "right": [
          "runtime/relative_vision/blue_right_01.png",
          "runtime/relative_vision/blue_right_02.png",
          "runtime/relative_vision/blue_right_03.png",
          "runtime/relative_vision/blue_right_04.png",
          "runtime/relative_vision/blue_right_05.png"
        ]
      }
    }
  }
}
```

- 基准 PNG 和贴挡 PNG 使用与标定相同的原位分辨率，并提前转正。相机实时帧的方向仍由现有 `profile` 和 `already_rotated` 设置决定。
- 每个 ROI 为 `[x1, y1, x2, y2]`，右、下边界不含。取左端板固定边、中段白轨前挡边和右端固定拐点，整组边缘要能约束横纵两轴，并给搜索留出边距。配准先做局部模板搜索，再以平移 ECC 精化。各区域的一致性、位移和相关度检查会拒绝出界或遮挡严重的帧。
- 杆身测量带使用基准帧的固定前挡边。若基准图不能自动拟合，可额外设置 `reference_rail_uv`，传入同一条白色前挡边下沿上两点 `[[u1,v1],[u2,v2]]`，按 u 递增且横向至少相隔 60 像素。运行时把前挡边、颜色检测窗口和导轨端点搜索窗口一起移到当前帧，并裁剪到画面范围。检测在原采样网格上完成，像素点回到基准坐标后再投影。
- 每侧止挡基准使用 5–10 张实际确认贴挡且机器人停稳时的独立图片。颜色为“蓝”或“橙”，侧名为 `left` 或 `right`，按模型轴方向。标定图片与任务图走同一配准、检测和投影链。程序检查有效帧和读数跨度，再以中值冻结基准。
- 使能时要求 `verification.aggregation` 为 `median`，且 `samples` 为 5–10。初始位置与停稳验收各取连续有效帧，保留 `max_spread_mm` 和原有目标窗口。配准、遮挡识别或幅度检查拒绝的帧会打断连续计数。运动前需要的止挡基准缺失或不稳定时，任务报告失败。

## 测量与任务记录

双边清楚时，沿用测量带逐行轮廓中点和截尾均值。单边遮挡时，用可见轮廓在导轨轴心平面解竖直圆柱的切线方程，按可见侧选根，保留 `occluded` 和逐行反算的一致性诊断。所有任务量按肩轴模型 X 的正负方向记录，单位为毫米。

- 相对模式的橙杆轮廓在相邻原生像素跨过颜色阈值时按阈值插值。颜色像素不包夹边界时使用形态学掩膜的像素边界位置。
- 检测结束后若帧龄超限，任务报 `camera_frame_stale_after_detection`，日志包含帧序号、帧龄、检测耗时和帧龄上限。该错误终止当前验收和任务，视觉质量拒帧仍按配置补采有效帧。
- 非目标杆读数不可靠时记录 `stationary_slider_unreliable`。可靠的非目标杆超出漂移阈值会拒帧，遮挡情形同时记录 `stationary_slider_drift` 和 `stationary_slider_occluded_drift`。
- 距离任务记录 `delta_x_mm`，即当前读数减该会话初始中值，并与预定增量比较。
- 往返任务去程若目标为止挡，使用实际贴挡基准确定增量。回程以会话起点、即增量 0 为验收参考。
- 止挡任务及被模型行程截断到止挡的距离任务记录 `d_stop_mm`，即当前读数减标定的贴挡中值。固定模型行程仍用于运动和起点约束。经过实测标定的止挡验收，可按该基准判断偏离，并在样本中记录与固定行程的偏差。
- 只有配有对应场景基准帧和有效贴挡数据的配置才能投入正式验收。采集位置已核实的到位、欠推和独立复测帧，通过实测区分能力来设定目标窗口。像素配准误差、毫米读数重复性和实际到位误差分别核验。
