# 路线分段控制

`hardware.segmented_motion.enabled=true` 是当前生产入口。该模式强制绕过旧 MotionRecovery、SpeedRecovery 调档、settling_bias 和 cartesian_compensation；即使误把旧恢复开关打开，也不会恢复这些动作。A6 只写当前规划节点，速度字段在 Free 为 1000、Push 为 6000（单位 0.01°/s），同一阶段不随误差变化。

参数集中在 `config/robot.json` 的 `hardware.segmented_motion`：Free 最大步长 0.2°；Push 起始 0.2°、每三个接触后节点增加 0.2°，上限 1.0°。撤离/返回使用 Free 参数，有限补推使用 Push 参数。原直线速度、接触参考点、安装偏移、视觉验收和 PID 不变。

在原密集 IK 路线上重新选点，保护笛卡尔拐角、单轴反向点和端点。候选关节弦继续通过原模型检查；缩短的几何段或端点余量不强行拉大。每轴模型差值和量化后的电机目标差值都受步长约束。首次命令相对该阶段实测起点检查，后续相对该轴在本阶段最后一次实际写出的 A6 检查，防止忽略微小副轴变化后累计出大跳变。

执行器保留原 Move 反馈和终点资格判定。小节点的主导轴目标必须实际写出才能继续推进，关闭旧的小步合并。细分路线的转向点允许在持续新鲜静止反馈且旧目标已在到位容差内时，使用静止方向余量发出正常转向；运动中的反向仍受原检查限制。阶段内因指令未能发出而停滞，也受原 2 秒无进展窗口约束。

速度字段表示驱动允许的速度，并非实测角速度保证。0.2° 是相邻指令的上限，不是实机定位精度；中途节点不要求停稳，终点仍按 ±0.3° 和保持时间判定。实际受力和振荡须由实机验证。
