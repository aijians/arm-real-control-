# 无相机双段直线测试

在开发板项目目录中，先退出正在运行的主程序和 PID 调试台，再执行：

```bash
cd /root/space_experiment/arm_real_control
bash run_line_test.sh --execute
```

顺序固定，括号内均为（大臂电机角，小臂电机角），单位度：

1. 从当前反馈姿态进入（164.96，53.09）。
2. 按末端笛卡尔直线到（146.00，51.06），采用现有 +x 接触参考点。
3. 先从第一终点沿同一参考点撤离至配置 entry_y_mm（当前 135 mm），再复位至配置 return_q_deg（当前几何角 180，4；当前电机角 177.84，5.50）。复位沿用现有大臂 >160°、小臂到位及停稳保持判据。
4. 进入（144.99，47.45）。
5. 按末端笛卡尔直线到（158.16，53.02），采用现有 -x 接触参考点；结束保持此目标，不再复位。

角度按最新 robot.json 中 offset/sign/ratio 转成几何角规划，执行时转回电机角，避免重复叠加偏置。直线参考点为生产运动学中的选定接触面等效点；不是两轴角度直接线性插值。起点进入及回零使用双轴关节插值。直线离散间隔不超过 0.25 mm，再按现有定时 A4 参数细分（当前每步不超过 0.2°、间隔 0.05 s、速度上限 60°/s）；到位后按现有反馈容差及停稳时间验收。

本脚本不调用相机、识别或任务系统，不写 PID，不改生产配置；手动给定路线仅检查关节限位、逆解连续性，不根据现场滑杆位置做避障。运行前自行确认沿途空间。失败即停止并退出，不重试或自动执行后续复位。运行中 Ctrl+C 终止并调用现有双轴停止逻辑；成功退出保留末端位置控制。

仅预览（不访问串口或相机）：

```bash
bash run_line_test.sh
```

若提示厂家 sal 扫描器占用串口，可用现有隔离机制，仅本次运行暂停并在退出时恢复：

```bash
bash run_line_test.sh --execute --isolate-sal
```

每次运行的计划、反馈和失败诊断单独保存在 `runtime/line_test/日期时间.json`，不会覆盖主程序 result.json。占用主程序同一个 task.lock；其他控制程序尚未退出时拒绝启动运动，不会主动结束这些程序。
